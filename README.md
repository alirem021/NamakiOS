## ✨ NamakiOS چیست؟

NamakiOS یک سیستم‌عامل آزمایشی کوچک با بوت‌لودر و کرنل x86، دسکتاپ گرافیکی، پنجره‌ها، ماوس و کیبورد است که داخل ماشین مجازی **QEMU** اجرا می‌شود. برای دیدن آن لازم نیست سیستم‌عامل اصلی کامپیوترتان را عوض کنید.

| بخش | امکانات |
|:--|:--|
| 🖥️ دسکتاپ | تصویر پس‌زمینه، منوی شروع، پنجره‌ها و محافظ صفحه |
| 🌐 مرورگر | نمایش سایت‌ها با موتور Chromium روی سیستم میزبان و انتقال تصویر و ورودی به NamakiOS |
| 🎙️ صدا | پخش صدا، میکروفون و دستیار صوتی «حسین» |
| 🧮 برنامه‌ها | ماشین‌حساب و مین‌روب |
| ⚙️ پایهٔ سیستم | بوت‌لودر، کرنل، ورودی ماوس و کیبورد، شبکه و درایورهای موردنیاز |

**نکتهٔ فنی:** مرورگر مدرن در خود کرنل اجرا نمی‌شود. Chrome یا Edge روی کامپیوتر میزبان صفحه را رندر می‌کند و NamakiOS تصویر آن را نمایش می‌دهد. بنابراین امکانات مرورگر به این پل ارتباطی و مرورگر میزبان وابسته‌اند.

## 🚀 دانلود و اجرا

1. از [**بخش Releases**](https://github.com/alirem021/NamakiOS/releases/latest) فایل `NamakiOS-Portable.zip` را دانلود کنید (حدود ۳٫۸ مگابایت). ZIP خودکار «Source code» در GitHub بستهٔ آمادهٔ اجرا نیست.
2. فایل ZIP را **کامل استخراج کنید** و پوشه‌ها و فایل‌های آن را کنار هم نگه دارید.
3. فایل مناسب سیستم خود را اجرا کنید:

| سیستم میزبان | فایل اجرا |
|:--|:--|
| Windows 64-bit | `run.bat` یا `run-windows.bat` |
| Linux x64 / ARM64 | `sh run.sh` |
| macOS Intel / Apple Silicon | `run-mac.command` یا `sh run.sh` |

در اجرای اول، لانچر وجود Python، QEMU، مرورگر Chromium و کتابخانه‌های لازم را بررسی می‌کند و **موارد موجود را دوباره دریافت نمی‌کند**. موارد کمبود را در کش خصوصی کاربر دانلود می‌کند؛ پس برای راه‌اندازی نخست ممکن است اینترنت و چندصد مگابایت فضای خالی لازم باشد. دفعات بعد از کش استفاده می‌شود. حجم کم ZIP به این دلیل است که فایل‌های اجرایی Python، QEMU و مرورگر داخل آن قرار ندارند. برای بازکردن سایت‌ها همچنان اتصال اینترنت لازم است.

`run.bat --check` در ویندوز یا `sh run.sh --check` در لینوکس و مک، وابستگی‌ها و مسیرهای اجرا را آماده و بررسی می‌کند. اجرای جداگانهٔ `setup-windows.bat` یا `sh setup.sh` اختیاری است.

**SHA-256 بستهٔ فعلی:** `eee2a2299fb7e319cb89f53eab31f61062b0e5e340583ebade4dfc7bdf0e5341`

> [!TIP]
> اگر در اولین اجرا دانلودی قطع شد، همان فایل اجرا را دوباره باز کنید. برای میکروفون، دسترسی میکروفون سیستم میزبان را فعال کنید. نبود میکروفون مانع بوت نمی‌شود.

## 📦 «پرتابل» دقیقاً یعنی چه؟

بستهٔ قابل‌انتقال شامل ایمیج آمادهٔ سیستم‌عامل، لانچرها، پل‌های صدا و مرورگر و فایل‌های لازم برای راه‌اندازی است. نصب دستی یا کامپایل پروژه لازم نیست. با این حال، **بسته کاملاً آفلاین نیست**: وابستگی‌های موجود نبودند، در اولین اجرا دانلود و در کش همان دستگاه ذخیره می‌شوند. برای بردن پروژه به دستگاه دیگر، همین ZIP را منتقل کنید؛ کش دستگاه قبلی لازم نیست.

| سیستم | محل پیش‌فرض کش وابستگی‌ها |
|:--|:--|
| Windows | `%LOCALAPPDATA%\NamakiOS\runtime` |
| Linux | `${XDG_CACHE_HOME:-~/.cache}/NamakiOS/runtime` |
| macOS | `~/Library/Caches/NamakiOS/runtime` |

با `NAMAKI_RUNTIME_CACHE` می‌توان محل کش را عوض کرد. `NAMAKI_STATE_DIR` محل لاگ‌ها و پروفایل مرورگر را تعیین می‌کند.

## 💡 نکات و محدودیت‌ها

- این پروژه در **QEMU** اجرا می‌شود؛ جایگزین نصب‌شدهٔ Windows، Linux یا macOS نیست.
- مرورگر برای خواندن و تعامل ساده با سایت‌ها مناسب است. ویدئوی روان، تب‌ها، دانلود فایل، کلیپ‌بورد، پنجره‌های پاپ‌آپ و تایپ فارسی هنوز یکپارچه نشده‌اند. متن فارسی نمایش داده می‌شود.
- مسیر دانلود خودکار Linux بر مبنای glibc 2.39 یا جدیدتر است. اجرای واقعی ویندوز بررسی شده؛ اجرای واقعی Linux و macOS در محیط توسعهٔ این نسخه بررسی نشده است.
- QEMU و Python دانلودشده با SHA-256 از پیش ثبت‌شده بررسی می‌شوند. وابستگی‌های دیگر طبق روش‌های توضیح‌داده‌شده در [راهنمای پرتابل](README-PORTABLE.md) دریافت می‌شوند.
- بخش HTTPS پروژه از BearSSL استفاده می‌کند؛ متن مجوز MIT آن داخل بستهٔ دانلودی قرار دارد.
- فایل‌های نسخهٔ پرتابل، اسکریپت‌های اجرایی، تنظیمات دانلود، مجوز BearSSL و ایمیج آمادهٔ سیستم‌عامل به‌صورت جداگانه در این مخزن دیده می‌شوند. ZIP همین نسخه در بخش Releases قرار می‌گیرد.
- **شفافیت دربارهٔ سورس:** `build/os-modern.img` یک ایمیج کامپایل‌شده است؛ سورس کامل بوت‌لودر و کرنل در این مخزنِ مخصوص نسخهٔ پرتابل قرار ندارد. فایل‌های ساخت، کش و داده‌های شخصی هم منتشر نمی‌شوند.
